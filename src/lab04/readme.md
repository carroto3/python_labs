## Реализованные интерфейсы

### 1. Printable (Печатаемый)

**Назначение:** Определяет контракт для объектов, которые можно выводить в разных форматах.

**Абстрактные методы:**
- `to_string()` — возвращает полное строковое представление объекта
- `to_short_string()` — возвращает краткое строковое представление объекта

**Реализация:**
```python
from abc import ABC, abstractmethod

class Printable(ABC):
    @abstractmethod
    def to_string(self):
        pass
    
    @abstractmethod
    def to_short_string(self):
        pass
