## 🏗️ Функциональность класса Apartment

### Атрибуты экземпляра

| Атрибут | Тип | Описание | Доступ |
|---------|-----|----------|--------|
| `address` | str | Адрес квартиры (≥5 символов) | Только чтение |
| `area` | float | Площадь (1-10000 м²) | Только чтение |
| `rooms` | int | Количество комнат (1-20) | Только чтение |
| `price` | float | Цена аренды (0-1000000 руб.) | Чтение/запись |

### Атрибуты класса

- `AVAILABLE_STATUSES` — кортеж допустимых статусов квартиры
- `_total_count` — общее количество созданных экземпляров
