# Lab02 - Класс ApartmentCatalog (Каталог квартир)

## 📋 Описание проекта

Проект расширяет **Lab01**, добавляя контейнерный класс **ApartmentCatalog** для управления коллекцией объектов `Apartment`.

**Новый функционал:**
- 🔹 Управление коллекцией (добавление, удаление)
- 🔍 Поиск по различным критериям (адрес, комнаты, цена)
- 📊 Сортировка (по цене, по площади)
- 📈 Статистические функции (средняя цена, максимум, минимум)
- 🎯 Поддержка протоколов контейнеров Python (`len`, `in`, `for`)
