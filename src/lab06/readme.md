## 3. Описание реализации

### 3.1. Типизированный класс `Apartment`
Класс недвижимости (квартиры) содержит аннотации типов для:
- параметров конструктора (`address: str`, `area: float`, `price: float`, `rooms: int`);
- всех атрибутов (через свойства с явным типом возврата);
- методов, например `price_per_sqm() -> float`.

Пример сигнатуры:
```python
class Apartment:
    def __init__(self, address: str, area: float, price: float, rooms: int) -> None:
        self._address: str = address
        ...
    def price_per_sqm(self) -> float:
        return self._price / self._area

3.2. Обобщённый контейнер TypedCollection[T]
Создан универсальный класс-контейнер, параметризованный типом T. Он хранит объекты произвольного, но фиксированного для конкретного экземпляра типа, обеспечивая типобезопасность.

Основные возможности:

add(item: T) -> None – добавление элемента.

remove(item: T) -> None – удаление элемента; выбрасывает ValueError, если элемент отсутствует.

get_all() -> List[T] – получение копии всех элементов.

get_by_index(index: int) -> T – доступ по индексу.

find(predicate: Callable[[T], bool]) -> Optional[T] – поиск первого элемента, удовлетворяющего условию.

__len__, __iter__ – поддержка len() и цикла for.

__str__, __repr__ – строковое представление.

Контейнер полностью повторяет интерфейс коллекции из ЛР-2, но с полной типизацией.
