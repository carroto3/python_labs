## Описание классов

### 1. Apartment (базовый класс)

**Атрибуты:**
- `address` (str) — адрес квартиры
- `area` (float) — площадь в м²
- `price` (float) — цена аренды в месяц (руб.)
- `rooms` (int) — количество комнат

**Методы:**
- `price_per_sqm()` — рассчитывает цену за квадратный метр
