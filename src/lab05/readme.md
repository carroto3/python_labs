# ЛР-5 — Функции как аргументы. Стратегии и делегаты

## Предметная область

**Недвижимость** — управление коллекцией квартир с помощью функций-стратегий.

## Цель работы

Освоение передачи функций как аргументов, использование функций высшего порядка (`sorted`, `filter`, `map`), 
реализация паттерна «Стратегия» и интеграция функционального подхода с ООП.

## Реализованные стратегии сортировки (3 шт.)

| Стратегия | Функция | Критерий сортировки |
|----------|--------|-------------------|
| 1 | `by_price()` | По цене аренды |
| 2 | `by_area()` | По площади |
| 3 | `by_price_per_sqm()` | По цене за м² (соотношение цена/площадь) |

---

## Реализованные функции-фильтры (4 шт.)

| Фильтр | Функция | Описание |
|-------|--------|---------|
| 1 | `is_affordable()` | Квартиры стоимостью до 50 000 руб. |
| 2 | `is_spacious()` | Просторные квартиры (от 60 м²) |
| 3 | `is_residential()` | Только жилые квартиры |
| 4 | `is_commercial()` | Только коммерческие помещения |

---

## Использованные возможности

- Передача функций как аргументов (`key=strategy`, `filter(filter_func, ...)`)
- Lambda-выражения
- Функции высшего порядка: `sorted()`, `filter()`, `map()`
- Комбинирование фильтрации и сортировки
- Полиморфизм при работе с объектами разных типов
