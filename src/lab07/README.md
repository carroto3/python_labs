# Лабораторная работа №7 — Итоговое CLI-приложение «Недвижимость»

## 1. Цель работы

Объединить знания, полученные в ЛР1–ЛР6, в единое работающее приложение.
Реализовано:

- **Объектно-ориентированное проектирование**: иерархия классов
  `Apartment → ResidentialApartment / CommercialApartment`
  с инкапсуляцией, наследованием и полиморфизмом (ЛР1, ЛР3).
- **Абстрактные интерфейсы** `Printable` и `Comparable` (ЛР4).
- **Трёхслойная архитектура**: разделение на слой представления (`cli.py`),
  бизнес-логики (`app.py`) и модели данных (`models.py`).
- **Интерактивный CLI-интерфейс** с меню, обработкой некорректного ввода
  и форматированным табличным выводом.
- **Пользовательские исключения** в отдельном модуле `exceptions.py`.
- **Операции поиска и фильтрации** (ЛР5): по атрибуту, по диапазону цен/площади,
  по количеству комнат, по статусу, по типу, по произвольному предикату.
- **Сохранение и загрузка** данных в формате JSON с полиморфной
  десериализацией (ЛР6).
- **Типизация** (type hints) во всех модулях.

## 2. Структура проекта

```
lab07/
├── README.md              # Документация проекта (этот файл)
├── main.py                # Точка входа, запуск CLI
├── cli.py                 # Интерфейс: меню, ввод, вывод (слой представления)
├── app.py                 # Бизнес-логика, управление данными (сервисный слой)
├── models.py              # Классы предметной области из ЛР1–ЛР6 (слой данных)
├── exceptions.py          # Пользовательские исключения
├── storage.py             # Сохранение и загрузка данных (JSON)
└── real_estate_data.json  # Файл данных (создаётся при сохранении)
```

### Назначение файлов

| Файл | Слой | Назначение |
|------|------|------------|
| `main.py` | Вход | Запуск приложения, передача параметров командной строки |
| `cli.py` | Представление | Меню, ввод/вывод, форматирование таблиц. НЕ обращается к коллекции напрямую |
| `app.py` | Бизнес-логика | `ApartmentManager` — CRUD, поиск, фильтрация, валидация |
| `models.py` | Данные | `Apartment`, `ResidentialApartment`, `CommercialApartment`, `Printable`, `Comparable` |
| `exceptions.py` | Ошибки | `ItemNotFoundError`, `DuplicateItemError`, `ValidationError`, `StorageError` |
| `storage.py` | Хранение | Сериализация/десериализация коллекции в JSON |

## 3. Описание CLI

### Пункты меню

| № | Пункт | Описание |
|---|-------|----------|
| 1 | Добавить объект недвижимости | Выбор типа (обычная/жилая/коммерческая), ввод атрибутов |
| 2 | Показать все объекты | Форматированная таблица со всеми объектами |
| 3 | Найти объект по атрибуту | Поиск по 9 атрибутам (без учёта регистра) |
| 4 | Фильтровать объекты | Подменю: цена, площадь, комнаты, статус, тип, предикат |
| 5 | Удалить объект | Удаление по ID |
| 6 | Сохранить данные | Сохранение коллекции в JSON |
| 7 | Загрузить данные | Загрузка коллекции из JSON |
| 8 | Сбросить к демо-данным | Восстановление 7 демонстрационных объектов |
| 0 | Выход | Предложение сохранить перед выходом |

### Обработка ошибок ввода

- **Неверный пункт меню**: сообщение `[!] Неверный пункт меню. Попробуйте снова.`
- **Ввод строки вместо числа**: перехват `ValueError`, сообщение `[!] Ошибка: введите число.`
- **Пустой адрес**: проверка на этапе ввода, операция отменяется.
- **Некорректные числовые значения**: валидация через `ApartmentManager.validate_float()/validate_int()`.
- **Попытка удалить несуществующий объект**: перехват `ItemNotFoundError`.
- **Ошибка сохранения/загрузки**: перехват `StorageError` с описанием проблемы.

### Сохранение и загрузка

Данные сохраняются в `real_estate_data.json` в формате JSON.
Каждый объект содержит поле `type` для полиморфной десериализации
(`Apartment`, `ResidentialApartment`, `CommercialApartment`).
При отсутствии файла загружаются демонстрационные данные
(7 объектов разных типов).

## 5. Вывод

В ходе выполнения лабораторной работы были изучены и применены
на практике следующие концепции:

- **Разбиение на модули и слои**: код разделён на 6 модулей,
  каждый с чёткой зоной ответственности. CLI зависит только от `app.py`,
  `app.py` зависит от `models.py` и `storage.py`.

- **CLI-интерфейс**: реализовано интерактивное меню с 8 операциями,
  подменю для фильтрации, цикл работы и обработка неверного ввода.

- **Обработка исключений**: иерархия `RealEstateError → ItemNotFoundError,
  DuplicateItemError, ValidationError, StorageError`. Каждое исключение
  перехватывается на уровне CLI с понятным сообщением.

- **Поиск и фильтрация (ЛР5)**: поиск по любому атрибуту, фильтрация
  по диапазонам, предикаты, лямбда-функции.

- **Работа с файлами**: сохранение/загрузка в JSON
  с полиморфной десериализацией через `create_apartment_from_dict()`.

- **Типизация**: аннотации типов во всех методах и функциях.
